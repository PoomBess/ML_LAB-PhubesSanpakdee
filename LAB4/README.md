# LAB 4: K-Nearest Neighbors (KNN)

## Description
ในแล็บนี้เป็นการศึกษาและสร้าง **Machine Learning Pipeline** ด้วยอัลกอริทึม **K-Nearest Neighbors (KNN)** โดยใช้ภาษา Python ซึ่งมีขั้นตอนการทำงานหลัก ดังนี้:

1. **Data Loading & Preprocessing:** นำเข้าข้อมูล และทำความสะอาดข้อมูลเพื่อให้อยู่ในรูปแบบพร้อมใช้งาน
2. **Feature Scaling:** ปรับสเกลของฟีเจอร์ (เช่น Normalization หรือ Standardization) เพื่อเพิ่มประสิทธิภาพการคำนวณระยะห่างระหว่างจุดข้อมูล
3. **Model Training:** ฝึกสอนโมเดล Classification / Clustering ด้วยอัลกอริทึม KNN
4. **Evaluation & Prediction:** ประเมินประสิทธิภาพของโมเดล และทดสอบทำนายผลข้อมูลใหม่
