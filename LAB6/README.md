# LAB 6: Neural Network (NN)

## Description
ในแล็บนี้เป็นการศึกษาและสร้าง **Neural Network Pipeline** ด้วยภาษา Python สำหรับงาน Image Recognition ซึ่งมีขั้นตอนการทำงานหลัก ดังนี้:

1. **Image Loading & Preprocessing:** นำเข้าไฟล์รูปภาพ และเตรียมข้อมูล เช่น การปรับขนาดรูปภาพ (Resizing) และ Normalization
2. **Dataset Splitting:** การแบ่งชุดข้อมูลออกเป็น Training Set และ Test Set เพื่อใช้ในการฝึกสอนและวัดผล
3. **Neural Network Training:** การสร้างและฝึกสอนโมเดลโครงข่ายประสาทเทียม (Neural Network) เพื่อเรียนรู้ฟีเจอร์ของรูปภาพ
4. **Evaluation & Prediction:** การประเมินประสิทธิภาพของโมเดล และนำโมเดลไปทดสอบทำนายผลรูปภาพใหม่
